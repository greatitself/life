# Life 0.8.0

Life 0.8 brings the streamlined preview interface to the installed desktop app.

- **A simpler new thread:** “What do you want to do in {project}?” uses a serif font. The dashed-underlined project name opens the project picker. Model and provider choices remain in the composer.
- **Customize from the header:** The paintbrush button opens Life Studio in a dialog, with saved customization conversations, drafts, build results, and recovery controls. Extension management lives inside this dialog.
- **A cleaner environment control:** Current Active Environment is a rounded pill without the line beneath it.
- **Readable running work:** Progress updates appear expanded between collapsed actions. Reasoning uses the reported action text without a “Reasoning summary” label. User and assistant messages no longer have an “Original message” control.
- **Focused completed turns:** Successful turns show the final parent response and “Worked for…” elapsed time. Submitted prompts remain visible and the saved transcript retains all provider events. Failed and interrupted work keeps its activity available.
- **Steer with Send:** During a running turn, Send turns yellow. Clicking it or pressing Enter steers the current response; Tab queues a follow-up. Shift+Enter inserts a newline. Empty Tab and modified Tab retain normal keyboard navigation.
- **Bring to Life:** Host chat history can continue existing Codex and Claude Code sessions with their original provider session IDs and project directories. Research, Studio, and internal metadata sessions keep their separate routes.

Update from Life 0.7.0 through **Updates → Check for updates**, then download and restart. Windows and Linux AppImage support in-app updates. macOS and Debian installations use the latest installer. The release includes installers, updater metadata, blockmaps, and SHA-256 checksums. Saved connections, chats, Research, and customization history remain in Life's existing data directory.
